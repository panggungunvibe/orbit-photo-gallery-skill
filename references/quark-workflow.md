# 夸克网盘 → 旅行记忆网站

本 Skill 编排网站制作；`quarkclouddrive` 提供账号授权、目录查询和文件下载。不要复制其 CLI、凭据或某个开发者的机器路径到本 Skill。通过当前环境的 Skill 列表定位它，并读取已安装版本的说明与所需引用文档。

## 路由与前置条件

- “把相册整理成旅行记忆”触发本 Skill 的完整网站制作流程。用户说的“整理”不意味着要在网盘内创建分类目录、复制相册或移动原片。使用夸克的只读列表和下载能力取得素材，随后在本地网站中分类。
- 已安装且已授权：直接继续，不重复申请同一账号的授权。
- 未安装：指出缺少夸克网盘 Skill，并引导安装官方 Skill；不能假装已经访问网盘。可先准备网站工程等不依赖账号的工作。
- 未授权或授权失效：执行夸克 Skill 所规定的授权流程，让用户完成必要步骤；等待期间可继续独立工程准备。不要要求用户把 Cookie、Token 写入本项目。
- 用户给的是虚拟相册，但连接能力只支持文件夹时，说明区别并请用户提供可访问的照片文件夹；不能以任意同名目录替代。

## 定位与获取

1. 从请求或会话读取相册/文件夹名。缺少名称时只问这一个信息，不先追问技术栈、字体、类目数量等可由既有审美决定的事项。
2. 按夸克当前文档选用文件夹搜索、完整目录浏览或相应相册接口。只读取用户指定范围；同名候选需要用户确认。不猜测目录 ID 或下载地址。
3. 下载所需的完整结果必须以工具返回的完整列表/Artifact 为准，不能只取前几条预览。读取其中的实际文件标识；遵守夸克的初始化、会话参数、分页、限速和失败处理规则。
4. 仅下载图片；记录视频或其他文件的数量并跳过。不把“找到了文件”作为最终结果——用户要的是网站。
5. 本地素材与联系表存放在独立的私人目录，原片与网站输出分开。授权信息不进入文件清单、代码、网页、日志展示或 Git。

## 增量更新与交付

重新获取已指定范围的当前完整列表，使用工具的文件身份规则以及返回的大小/哈希等可靠信息判断新增或变化。复用已成功下载且可确认未变化的素材；跨批次检查同一图片、相近连拍和拼图中的重复画面。不在没有新请求或新信息时重复下载。

从联系表与候选原片完成视觉筛选后，回到主 Skill 的分类、文案与编码流程。智能体负责生成 `selection.json` 和执行所有导入命令，用户不用手工准备清单。

最终交付的是完整代码和正在运行的本地预览。没有公开发布指令时，不能把含照片的项目推送到公开仓库或部署到公网。本 Skill 的 GitHub 仓库只发布通用模板与示例素材。
